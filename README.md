
# Projet 9 — Analyse des ventes de la librairie Lapage avec Python

## Présentation du projet

Ce projet a été réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

L'objectif est d'analyser les ventes de la librairie Lapage pour mieux comprendre son activité commerciale, les comportements de ses clients et les performances des différentes catégories de produits.

## Problématique métier

Comment exploiter les données commerciales pour identifier les tendances des ventes, mieux connaître les clients et faciliter la prise de décision ?

## Jeux de données

- Transactions.csv : historique des ventes de mars 2021 à février 2023.
- customers.csv : informations sur les clients.
- products.csv : informations sur les produits.

Les jeux de données ne sont pas publiés dans ce dépôt.

## Méthodologie

1. Importation et exploration des données.
2. Nettoyage et préparation avec Python et Pandas.
3. Analyse du chiffre d'affaires et des ventes.
4. Étude des catégories de produits.
5. Analyse des comportements clients.
6. Visualisation et interprétation des résultats.

## Compétences mobilisées

- Python
- Pandas
- Analyse exploratoire des données
- Nettoyage et préparation des données
- Analyse commerciale
- Data Visualisation
